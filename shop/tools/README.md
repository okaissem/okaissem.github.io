# 4종목 라이더 쇼핑몰 (쥬얼리 · 모자 · 의류 · 가방) - 상품 넣는 방법

상품 4,000개는 하나씩 손으로 넣지 않고, 고객이 채운 엑셀을 한 번에 바꿔서 넣습니다.

## 순서

1. **고객에게 엑셀 양식 보내기** - `상품등록_양식_4종목_4000개.xlsx`
   (양식을 다시 만들 때: `python3 shop/tools/make_template.py shop/tools/상품등록_양식_4종목_4000개.xlsx`)
2. **채운 엑셀과 사진 받기** - 사진은 엑셀에 적힌 파일 이름 그대로 `shop/images/` 폴더에 넣습니다.
3. **상품 데이터 만들기**

   ```
   pip install openpyxl
   python3 shop/tools/excel_to_products.py 받은엑셀.xlsx
   ```

   `shop/data/products.js` 가 새로 만들어지고, 종목별 개수와 **고칠 줄**(필수 항목 빠짐, 상품코드 중복, 종목 이름 틀림)이 화면에 나옵니다.
   고칠 줄은 홈페이지에 들어가지 않으니 고객에게 알려 주세요. 판매상태가 `숨김`인 상품도 빠집니다.
4. `shop/index.html` 안의 `?v=` 숫자를 바꾸고 올리면 손님 휴대폰에도 새 상품이 바로 보입니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `make_template.py` | 고객에게 보낼 엑셀 양식을 만듭니다 |
| `excel_to_products.py` | 채운 엑셀 → `data/products.js` |
| `make_sample_products.py` | 시안용 가상 상품 4,000개를 만듭니다 (실제 상품을 넣으면 쓰지 않습니다) |

색상 이름이 새로 나오면 `shop/config.js` 의 `colors` 에 색을 추가해 주세요. 없으면 회색 점으로 보입니다.

## 유튜브 영상에 넣을 링크

영상 설명란이나 고정 댓글에 아래처럼 넣으면, 누른 손님에게 그 상품이 바로 열립니다.
회원가입이 필요 없고, 상담·주문 메시지에 "유튜브 영상 보고 연락드려요"가 붙어 유튜브 손님인지 알 수 있습니다.

| 열 화면 | 주소 |
|---|---|
| 특정 상품 | `https://okaissem.github.io/shop/?from=youtube&id=CL-0001` (상품코드) |
| 종목 전체 | `https://okaissem.github.io/shop/?from=youtube&cat=의류` |
| 첫 화면 | `https://okaissem.github.io/shop/?from=youtube` |

## 결제 (홈페이지 안에서 받기)

손님은 회원가입 없이 장바구니 → 주문서(성함·휴대폰·주소) → **토스페이먼츠 결제창**(카드·간편결제·계좌이체)으로 결제합니다.
상담은 상품 화면의 **카톡으로 상담하기** 버튼으로 받습니다 (상품 정보가 담긴 메시지가 복사되고 카카오톡 채널이 열립니다).

지금은 토스페이먼츠 문서에 공개된 **테스트 키**라 실제 돈이 나가지 않습니다. 실제로 결제를 받으려면:

1. 사업자등록, 통신판매업 신고
2. 토스페이먼츠 가입과 심사 → 상점관리자에서 **결제위젯 연동 키**(클라이언트 키)를 받아 `shop/config.js` 의 `pay.clientKey` 에 넣기
3. **결제 승인 서버** 만들기 - 결제가 끝나면 금액이 주문과 같은지 확인하고 토스페이먼츠에 승인을 요청하는 작은 서버입니다.
   시크릿 키는 이 서버에만 두고, 홈페이지 파일에는 절대 넣지 않습니다. 주소를 `pay.confirmUrl` 에 넣으면 결제 완료 화면이 이 서버를 거칩니다.
   이 서버가 주문 내용(받는 분·주소·상품)을 가게에 알려 주는 일(문자·카톡 알림·메일)도 함께 맡습니다.
4. 카카오톡 채널 채팅 주소를 `links.kakao` 에 넣기

결제가 끝나면 `order-complete.html` 로 돌아와 주문 내용을 보여 주고, 장바구니에서 결제했으면 장바구니를 비웁니다.
