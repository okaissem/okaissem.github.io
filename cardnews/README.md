# 홈페이지 제작 홍보 카드뉴스

자영업자·사업자에게 홈페이지 제작을 알리는 카드뉴스입니다. 사진과 화면은 모두 이 저장소의 시안(과일철이네2, Finest Jewelry)에서 가져왔습니다.

| 파일 | 크기 | 쓰는 곳 |
| --- | --- | --- |
| `00-banner.png` | 1448×1086 | 대표 이미지 (블로그·크몽·당근 등) |
| `01-cover.png` ~ `05-price.png` | 1080×1350 | 인스타그램 카드뉴스 5장 (순서대로 올리기) |

1. 표지 — 사장님 가게, 홈페이지 있으세요?
2. 디자인 — 업종에 맞춘 디자인 (과일가게 · 쥬얼리 쇼핑몰)
3. DM 주문 — 누르면 주문서, DM으로 바로
4. 유튜브 — 영상 보고 바로 주문
5. 가격 — 기본형 50만 · 표준형 90만 · 프리미엄 150만 원 (VAT 별도, `pricing/` 가격표와 같음)

## 문구·가격 고치기

`src/cardnews.html` 의 글자를 고친 뒤 `src/render.js` 로 PNG를 다시 뽑습니다 (방법은 파일 맨 위에 있습니다).
`src/shots/` 는 카드에 들어간 홈페이지 화면(미리보기 표시를 끄고 찍은 것)입니다.
